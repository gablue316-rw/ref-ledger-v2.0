Import Instructions

  1. Download the Games CSV template.
  2. Open the template in Excel, Google Sheets, or another spreadsheet program.
  3. Enter one game per row.
  4. Notes are optional and limited to 150 characters. Keep the notes column as the last column, even when notes are blank.
  5. Do not change the column headings.
  6. Save or export the completed file as CSV.
  7. Select the file below and preview it before importing.
  8. After making corrections, save the CSV and preview again. Follow the browser instructions below about selecting the file again.
